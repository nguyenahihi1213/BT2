# Bài tập 1: Kiểm tra số nguyên tố (C++)

## Mô tả bài toán
Viết chương trình C++ nhận vào một số nguyên `n` từ bàn phím và kiểm tra xem `n` có phải là số nguyên tố hay không.

- **Số nguyên tố** là số nguyên lớn hơn 1 và chỉ chia hết cho 1 và chính nó (ví dụ: 2, 3, 5, 7, 11...).
- **Đầu vào (Input):** Một số nguyên `n`.
- **Đầu ra (Output):** Thông báo `n` là số nguyên tố hoặc không phải là số nguyên tố.

## Yêu cầu môi trường
- Trình biên dịch C++ (ví dụ: GCC / MinGW / Clang).

## Cách chạy chương trình

1. Clone repository về máy:
   ```bash
   git clone https://github.com/nguyenahihi1213/BT2.cpp

   cd BT2
   ```

2. Biên dịch chương trình:
   ```bash
   g++ main.cpp -o main
   ```

3. Chạy chương trình:
   - **Trên Windows:**
     ```bash
     main.exe
     ```
   - **Trên macOS / Linux:**
     ```bash
     ./main
     ```
